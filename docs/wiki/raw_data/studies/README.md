## Notes / observations
- GEO accessions GSE114727/GSE114724 and GSE123813/GSE123814 are SuperSeries pairs — expect cross-source dedup overlap.
- GSM6911623 is a single sample contained within parent GSE222011.
- All custom cohorts (acsr*, kobs, lung_va, etc.) currently lack public-citation provenance — flagged as "unknown — needs investigation" per cohort page; recommend the Input Data Curator engage internal stakeholders to collect IRB/protocol documentation.
- A small number of GEO IDs in the geo/ subdir (e.g. GSE145596) are mouse-only and should be filtered before TCR ingestion.
- Two studies appear without TCR data on disk despite parent papers including TCR work (GSE110684, GSE121810, GSE165080, GSE182109, GSE186344, GSE188737, GSE193745, GSE216005, GSE218743, GSE234129, etc.) — these are listed as **unused** for QUEST TCR modeling.

## Per-study fidelity tiers (count)
- Tier 5 (Gold — paired TCR + epitope/MHC): 4 studies (GSE222011, GSE232447, ZEN14010377, ZEN7555405, ZEN8140861)
- Tier 4 (High — paired single-cell TCR with disease/cell metadata): ~20+ studies
- Tier 3 (Medium — case/control bulk TCR or limited paired): ~10 studies
- Tier 2 (Bulk repertoires — MLM only): all custom cohorts plus a few bulk-only GEOs
- Tier 1 (Limited / unused — no TCR on disk): ~15 GSEs in geo/ and top-level
